# Original LibreEvolve artwork

The original **Diff Arrow** branding was created on March 18, 2026 and is
restored from commit `8579b3ae2d5e73b60b1eef6d0ee0d3e36a231dcf`.

- [Dark-background SVG mark](../logo-mark.svg)
- [Light-background SVG mark](../logo-mark-light.svg)
- [Full branding preview](branding-preview.html): open this HTML file in a
  browser to see the wordmark, size variants, palette, typography and social card.
- [Original design specification](original-spec.md)

The preview and specification are preserved historical design references, not
current product documentation. Their feature descriptions, test/paper counts
and example commands do not describe today's engineering preview. The spec
also lists proposed exports that were not present in the original commit;
this restoration does not supply those missing exports.

The preview uses Google Fonts when online, with local font fallbacks. Its
artwork is embedded SVG/CSS; it contains no JavaScript.

See the root [README](../../README.md) for current product scope and the
repository [MIT license](../../LICENSE).
