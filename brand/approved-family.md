# Approved visual family

This page records the public-safe integration contract for the approved
LibreEvolve raster family. The fingerprints below identify the exact PNG
bytes used by the local static build; they are content hashes, not signatures,
vector-master claims, or deployment approval.

## Visual thesis

LibreEvolve should feel like a precise developer instrument: a dark identity
plane, editorial type, generous space, and one green accent around inspectable
evidence. The approved four-part Diff Arrow is the dominant visual anchor. It
appears at generous size beside the short preview promise, while the simplified
micro mark carries compact identity where the full grammar would become fragile.

## Content plan

1. **Identity and scope** — name the engineering preview and its bounded
   Python bin-packing lane.
2. **Evidence** — state what a run can and cannot establish, without inventing
   a result, screenshot, or metric.
3. **Workflow** — show the change, evaluate, inspect, and export sequence.
4. **Setup and limits** — give the canonical quickstart and keep host access,
   usage, and publication boundaries visible.

## Interaction thesis

The page uses three restrained cues: a brief identity entrance, native
expandable navigation with keyboard escape, and clear focus/hover transitions
on links and the primary action. The theme control changes the presentation
family without changing the copy or evidence state. Reduced-motion users keep
the same information and controls with transitions removed.
