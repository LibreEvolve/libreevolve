# LibreEvolve documentation

LibreEvolve is an engineering preview for bounded Python bin-packing
optimization with Codex OAuth. Read the [quickstart](alpha-quickstart.md)
before requesting subscription-backed work; it is the single maintained source
for clone, install, offline, seed-only and live commands.

## Start and understand

- [Engineering-preview quickstart](alpha-quickstart.md): support matrix,
  installation, offline preflight, seed-only inspection, optional live route,
  collision behavior and source selection.
- [Reading saved results](results.md): status, validity, quality, retention,
  held-out checks, usage and no-result outcomes.
- [Safety and scope](safety.md): host-access execution, credentials, local
  artifacts, holdout boundaries and subscription-use limits.
- [Saved artifact contract](run-artifacts.md): persisted files, provenance,
  incomplete state and fail-closed behavior.

## Work on the project

- [Contributing](contributing.md): focused changes, offline checks and review
  expectations.
- [Development checks](development.md): the retained test suite and package
  build/provenance checks.
- [Roadmap](roadmap.md): what is available today and what remains future work.
- [Release checklist](release-checklist.md): source, distribution and
  publication gates.

The public source repository is
[LibreEvolve/libreevolve](https://github.com/LibreEvolve/libreevolve). The
documentation describes source and local artifacts only; it does not claim a
published package, deployed website, hosted CI result, fresh live run or
external usability.
