# Completed Todo Archive Policy

This directory stores completed todo items moved out of the active backlog in `docs/todo/*.md`.

Ongoing rule for the AlphaEvolve-alignment goal:

- Keep open work as unchecked task items in `docs/todo/code.md`, `docs/todo/readme.md`, `docs/todo/roadmap.md`, and `docs/todo/papers.md`.
- When an item is actually implemented, tested, and documented, move its full task block into the matching file under this directory and mark it complete.
- Do not leave completed task items in the active backlog files.
- Before any goal handoff or completion claim, verify that active backlog files
  contain no checked task markers and completed archive files contain no
  unchecked task markers.
