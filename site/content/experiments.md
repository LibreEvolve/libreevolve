# Experiments

No approved live experiment is published in this local website build.

The example viewer must use reviewed, frozen evidence. A seed-only check or
synthetic fixture is not a live-model demonstration, and a rendered result is
not permission to publish its source or provenance.

## What an experiment should show

- The public source and environment identities, or explicitly unknown values.
- The task, selection rule and authorized call/runtime limits.
- Run completion or cancellation separately from candidate validity and retention.
- Baseline and candidate checks on the same named corpus and split.
- Held-out reporting after selection, without using it as a tuning target.
- Observed usage, missing usage, limitations and unsuccessful attempts.

Improved, unchanged and worse outcomes should be presented honestly. Bin-packing
quality is not accuracy or speed. Finite checks and hashes are not independent
attestation, universal correctness or optimality.

Read the [evidence guide](../../docs/results.md), then
[run the preview](../../docs/alpha-quickstart.md) if you want to inspect your own
bounded experiment. Live subscription use is a separate choice.
